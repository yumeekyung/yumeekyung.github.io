Onimal Website

Project Overview

오니몰은 오가닉(Organic)과 애니멀(Animal)을 합친 이름의 스킨케어 브랜드입니다.

꽃이 피는 숲을 걷는 사슴 한 마리 — 펜으로 직접 그린 일러스트에서 시작한 브랜드가 어떤 철학으로 제품을 만드는지

효과적으로 전하기 위해, 브랜드 메시지와 제품 이야기를 담은 웹사이트와 제품 상세페이지를 설계했습니다.

자연에서 온 순한 성분, 숲의 생기, 손으로 그린 온기를 블랙 · 아이보리 · 그레이 세 가지 톤 안에서 차분하게 보여 줍니다.

오가닉 + 애니멀

오니몰은 자연에서 온 순한 성분과 숲을 거니는 생명의 건강한 생기를 피부에 담고자 만든 스킨케어 브랜드로,

덜어내고 남긴 사슴 한 마리로 브랜드를 기억하게 하는 단순하고 고요한 아름다움을 지향합니다.

Website Overview

새롭게 선보이는 Deer Bloom 라인을 매력적으로 소개하는 것을 목표로 했습니다.

Website Core Value

처음 오니몰을 만나는 사용자도 브랜드를 쉽게 이해할 수 있도록, 텍스트보다 이미지 위주로

제품 라인의 분위기와 일러스트의 디테일을 직관적으로 전달하고자 했습니다.
